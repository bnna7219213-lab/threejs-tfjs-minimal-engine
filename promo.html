CORE THESIS

为什么是神经符号？

黑盒生成的几何不可解释、不可编辑、常有伪影。程序化 SDF 每一步可读，用户可修改参数。神经网络负责理解语义，符号系统负责精确执行。

纯黑盒生成 (3D-GAN / NeRF)

✗不可解释：无法知道为什么生成这个形状
✗不可编辑：改不了一个参数
✗几何有伪影：非水密 mesh，法线错乱
✗需要大量 3D 标注数据
✗高分辨率显存爆炸

神经符号管线 (LSTM + SDF + MC)

✓每一步操作可读，操作序列即中间表示
✓用户可修改参数 / 增删操作 / 重排序
✓SDF 数学保证水密 mesh，法线即梯度 ∇f
✓合成数据自监督，无需人工标注
✓SDF 可自适应采样，内存可控

ARCHITECTURE

三层架构

每层可独立测试，每层可编辑，每层可微

L1 · DECODER

LSTM 序列解码器

将文本上下文向量解码为 SDF 操作序列。op_head 预测操作类型，arg_head 预测连续参数。自回归生成，支持 Teacher Forcing 训练。

# LSTM Decoder
class SDFDecoder:
  LSTM(256, layers=2)
  op_head  = Linear(256, vocab)
  arg_head = Linear(256, 4)
  for t in max_ops:
    op  = op_head(out)
    arg = arg_head(out)
    yield (op, arg)
L2 · SDF ENGINE

SDF 程序化执行器

每个操作对应可微 SDF 基元。用 CSG 布尔运算 (min/max) 组合。操作序列是可编辑的中间表示。

# SDF Primitives
sphere(c,r)   = |p-c| - r
box(c,s)      = max(|p-c|,0) + min(max(|p-c|),0)
cylinder(a,r,h) = max(|p_xy-a|-r, |p_z|-h/2)

# CSG Boolean
union(A,B)     = min(A, B)
subtract(A,B)  = max(A, -B)
smooth(A,B,k)  = smoothMin(A, B, k)
L3 · SURFACE

Marching Cubes

从 SDF 距离场提取精确三角 Mesh。128 面三角化表，线性插值求交点，SDF 梯度 ∇f 即法线。50³ 网格 CPU 实时。

# Marching Cubes
for cube in grid:
  if 8-verts sign mismatch:
    tri = lookup(128_table)
    pts = lerp(sdf, iso_level=0.0)
    nrm = gradient(sdf)  # ∇f
    yield (pts, tri, nrm)
TRAINING

训练策略

两阶段：先用模仿学习让系统跑起来，再用端到端可微做精细优化

PHASE A · 启动快

方案 A：模仿学习

程序化合成 (文本描述, SDF 操作序列) 配对数据，无需人工标注。Teacher Forcing 训练，损失为操作类型 CrossEntropy + 参数 MSE。

# 合成数据生成器
gen_pair:
  text = "a table with 4 legs"
  ops  = [sphere, translate, cylinder×4, for_loop]
  yield (text, ops)

# 损失函数
loss = CrossEntropy(op_pred, op_gt)
     + MSE(arg_pred, arg_gt)
PHASE B · 最终目标

方案 B：端到端可微

LSTM → SDF → [Soft MC / DMTet] → Chamfer Distance。梯度一路反传到 LSTM 参数。MC 用 Soft Rasterizer 或 DMTet 替代实现可微。

# 端到端训练
sdf   = decoder(text)
mesh  = soft_mc(sdf)
loss  = chamfer(mesh, gt_mesh)
loss.backward()  # LSTM 参数更新

# Chamfer Distance
CD = mean(min(d(P,G))) + mean(min(d(G,P)))
